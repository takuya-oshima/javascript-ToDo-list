# javascript-ToDo-list

JavaScript（フレームワークなし）でDOM操作を学ぶために作成したToDoリストです。

[StackBlitz](https://stackblitz.com/edit/vitejs-vite-x9y1se)

TODOの追加・削除・完了・未完了への戻しができます。

同じToDoリストをReactで作り直したものが [react-ToDo-list](https://github.com/takuya-oshima/react-ToDo-list) です。

## 使用技術

HTML / CSS / JavaScript

## 学んだこと

- `createElement` や `appendChild` による要素の生成と追加
- `closest` などを使った、クリックされたボタンから対象の要素をたどる方法
- DOMを直接操作する書き方と、Reactの状態管理による書き方の違い
